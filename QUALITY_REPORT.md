# Отчёт о качестве моделей

Дата проверки: 2026-11-03.

## Методика

- Walk-forward: обучение только на датах до тестового периода.
- Три последовательных тестовых окна по 60 торговых дней.
- Загружены все 511 инструментов TQBR; 254 прошли требования по истории.
- Комиссия: 10 базисных пунктов при изменении позиции.
- Сигнал рассчитывается после закрытия, вход — на открытии следующего дня.
- Разрывы цены больше 25% исключаются как корпоративные события/аномалии.
- Все признаки рассчитываются только по данным, известным на дату прогноза.

## Conv1D-регрессия

На 1 800 прогнозах:

- точность направления: 51,94%;
- MAE: 1,71% против 1,57% у нулевого прогноза;
- корреляция прогноза с результатом: 0,029;
- средняя long/cash-доходность после комиссии: −3,67%.

Регрессионная модель не превосходит нулевой baseline по ошибке.

## CatBoost down/flat/up на всех тикерах

Порог класса: ±0,3%. Порог вероятности сделки выбирается только на внутренней
validation-выборке каждого fold. Итоговый тест содержит 45 007 прогнозов.

- обычная accuracy: 46,23%;
- balanced accuracy: 36,88%;
- momentum accuracy: 38,98%;
- средняя long/cash-доходность после комиссии: +1,52%;
- медианная доходность по тикеру: +1,08%;
- прибыльных тикеров: 143 из 254;
- активных сигналов: 3 089;
- momentum long/cash: −13,09%.

Модель превосходит momentum, но почти не распознаёт класс `flat`, а преимущество
стратегии умеренное. Положительный исторический тест не доказывает будущую
доходность.

## Вывод

Модель подходит для исследовательской беты, но не для продажи торговых сигналов.
Перед монетизацией нужны более длинная live-проверка, дополнительные периоды
рынка и статистически значимое число независимых сигналов.

Повторный запуск:

```bash
.venv/bin/python backtest_direction.py \
  --tickers all \
  --max-tickers 0 \
  --days 1500 \
  --iterations 500 \
  --volatility-threshold-multiplier 0 \
  --folds 3
```
