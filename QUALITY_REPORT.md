# Отчёт о качестве моделей

Дата проверки: 2026-11-03.

## Методика

- Walk-forward: обучение только на датах до тестового периода.
- Три последовательных тестовых окна по 60 торговых дней.
- Загружены все 511 инструментов TQBR; 254 прошли требования по истории.
- Комиссия: 10 базисных пунктов при изменении позиции.
- Сигнал рассчитывается после закрытия, вход — на открытии следующего дня.
- Разрывы цены больше 25% исключаются как корпоративные события/аномалии.
- Все признаки рассчитываются только по данным, известным на дату прогноза.

## Conv1D-регрессия

На 1 800 прогнозах:

- точность направления: 51,94%;
- MAE: 1,71% против 1,57% у нулевого прогноза;
- корреляция прогноза с результатом: 0,029;
- средняя long/cash-доходность после комиссии: −3,67%.

Регрессионная модель не превосходит нулевой baseline по ошибке.

## CatBoost down/flat/up на всех тикерах

Порог класса: ±0,3%. Порог вероятности сделки выбирается только на внутренней
validation-выборке каждого fold. Итоговый тест содержит 45 007 прогнозов.

- обычная accuracy: 46,23%;
- balanced accuracy: 36,88%;
- momentum accuracy: 38,98%;
- средняя long/cash-доходность после комиссии: +1,52%;
- медианная доходность по тикеру: +1,08%;
- прибыльных тикеров: 143 из 254;
- активных сигналов: 3 089;
- momentum long/cash: −13,09%.

Модель превосходит momentum, но почти не распознаёт класс `flat`, а преимущество
стратегии умеренное. Положительный исторический тест не доказывает будущую
доходность.

## Бинарный торговый сигнал

Отдельная модель обучается на направлении `next open → next close`. Движения
меньше 0,3% не участвуют в обучении. Вероятности калибруются методом Platt,
а пороги `up` и `down` допускаются независимо на внутренней validation-выборке.

На 44 888 out-of-sample наблюдениях:

- precision подтверждённых сигналов: 57,94%;
- precision на движениях больше 0,3%: 57,36%;
- coverage: 48,96%;
- подтверждённых сигналов падения: 21 978;
- подтверждённых сигналов роста: 0.

Сигналы роста отключены автоматически, поскольку не достигли 55% validation
precision. Это предотвращает убыточную long-стратегию, но означает, что модель
пока пригодна только как предупреждение о возможном снижении.

## LightGBM и ансамбль

Добавлены признаки открытия/закрытия, положения цены внутри дневного диапазона,
изменения оборота и режима индекса IMOEX. На том же walk-forward-периоде:

- CatBoost: precision 57,63%, coverage 43,77%;
- LightGBM: precision 60,20%, coverage 35,56%;
- ансамбль 50/50: precision 58,66%, coverage 39,52%.

LightGBM лучше в среднем по тестовым fold, однако на самом свежем внутреннем
validation-периоде не прошёл минимальный порог precision ни для одного
направления. Поэтому он сохранён как исследовательская модель, но бот продолжает
использовать CatBoost. Автоматическая замена модели без свежей валидации
запрещена.

## Проверка устойчивости

Расширенный отчёт учитывает комиссию 10 bps, проскальзывание 5 bps, bootstrap
confidence intervals, калибровку и разрезы по времени и режимам рынка.

Для LightGBM:

- precision: 60,20%, 95% CI `[59,46%; 60,95%]`;
- log loss: 0,6827;
- Brier score: 0,2448;
- expected calibration error: 2,45%;
- precision в uptrend: 63,15%;
- precision в sideways: 58,97%;
- precision в downtrend: 57,06%;
- precision при высокой волатильности: 35,42%;
- в одном из трёх fold модель не выдала ни одного допустимого сигнала.

Диагностика показала, что адаптивный selector необоснованно отключал весь второй
fold, хотя фиксированный калиброванный порог 55% сохранял precision выше 55%.
Дополнительная ошибка приходилась на режим volatility ≥2%.

Для стабильной LightGBM warning-policy зафиксированы:

- только подтверждённые сигналы `down`;
- минимальная вероятность падения 55%;
- при market volatility ≥2% возвращается «сигнала нет».

Результат policy:

- precision: 61,17%, 95% CI `[60,52%; 61,75%]`;
- coverage: 52,70%;
- fold precision: 60,80%, 62,16%, 60,53%;
- precision по ликвидности: 59,00–62,61%;
- warning quality gate: пройден.

Long/trading gate остаётся непройденным, поскольку подтверждённых `up`-сигналов
нет. Policy выбрана после анализа исторических fold, поэтому её следующий
обязательный этап — проверка на новых live-данных без изменения порогов.

## Вывод

Модель подходит для исследовательской беты, но не для продажи торговых сигналов.
Перед монетизацией нужны более длинная live-проверка, дополнительные периоды
рынка и статистически значимое число независимых сигналов.

Повторный запуск:

```bash
.venv/bin/python backtest_direction.py \
  --tickers all \
  --max-tickers 0 \
  --days 1500 \
  --iterations 500 \
  --volatility-threshold-multiplier 0 \
  --folds 3
```
